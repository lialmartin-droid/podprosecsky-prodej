# Podprosečské domácí produkty V16

## Novinky
- informační banner spravovaný z administrace
- dočasné pozastavení objednávek a denní limit objednávek
- předobjednávky s plánovanou kapacitou a počtem rezervací
- volba rozdělení kombinované objednávky na dvě vyzvednutí
- volba SMS nebo e-mailu pro ruční kontakt den před vyzvednutím
- potvrzovací e-mail s oslovením křestním jménem
- dashboard, měsíční tržby, TOP produkty a TOP zákazníci
- rozšířený kalendář vyzvednutí

## Instalace
1. Nahrajte obsah ZIPu na GitHub přes stávající soubory.
2. Nahraďte celý obsah Code.gs přiloženým souborem.
3. Uložte Apps Script a vytvořte novou verzi webové implementace.
4. Funkci setup() není nutné znovu spouštět.
5. Proveďte tvrdé obnovení stránky.
