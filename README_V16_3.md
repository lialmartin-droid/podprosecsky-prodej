# V16.3 – komunikace a čísla objednávek

- Číslo objednávky PP-ROK-0001 je vidět v administraci i e-mailech.

- Při změně stavu na Připraveno se zákazníkovi s volbou E-mail odešle zpráva automaticky.
- Rozdělené objednávky odesílají připravenost každé části samostatně.
- Ochrana proti automatickému dvojímu odeslání.
